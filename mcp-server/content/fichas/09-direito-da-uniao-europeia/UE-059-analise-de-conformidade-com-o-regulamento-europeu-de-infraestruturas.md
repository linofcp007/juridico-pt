# Análise de Conformidade com o Regulamento Europeu de Infraestruturas de Dados de Saúde (EHDS — Regulamento (UE) 2025/327)

> **Âmbito:** UE · **Área:** Direito da União Europeia · **Código:** UE-059
> **EN:** Compliance Analysis under the European Health Data Space Regulation (EHDS — Regulation (EU) 2025/327). Analyses the obligations of healthcare providers, health data holders and health data users under Regulation (EU) 2025/327 (European Health Data Space — EHDS), including portability of the electronic health record, the regime for secondary use of health data and GDPR (RGPD) compliance in the health context.

### ETAPA 2 — ANÁLISE JURÍDICA
Dentro de <fundamentos_juridicos>:
- Uso primário de dados de saúde (Capítulo II EHDS):
  • Direito do paciente de aceder ao seu registo de saúde eletrónico em formato interoperável (ponto de acesso nacional)
  • Obrigação dos prestadores de saúde de disponibilizar os dados no formato europeu de intercâmbio (EEHRxF)
  • Portabilidade para outros EM da UE via MyHealth@EU
  • Direito de complementar e retificar o registo; direito de restrição de acesso a determinados prestadores
- Uso secundário de dados de saúde (Capítulo III EHDS):
  • Organismos responsáveis pelo acesso a dados de saúde (ORAD): entidades nacionais que autorizam o acesso; em Portugal [■ VERIFICAR: entidade designada]
  • Autorização de acesso (data permit): investigação científica; ensino; formulação de políticas; segurança de produtos de saúde; interesse público
  • Formato de dados pseudonimizados; proibição de reidentificação; proibição de uso para decisões adversas ao titular
  • Pedido de dados ao ORAD: formulário; prazo de decisão; recurso de recusa
- Articulação com RGPD: dados de saúde são categoria especial (art. 9.º RGPD); o EHDS cria bases de licitude específicas para uso primário e secundário; DPIA obrigatória
