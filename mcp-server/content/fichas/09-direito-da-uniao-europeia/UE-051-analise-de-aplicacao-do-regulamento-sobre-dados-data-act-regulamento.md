# Análise de Aplicação do Regulamento sobre Dados (Data Act — Regulamento (UE) 2023/2854) a Produtos Ligados e Serviços Relacionados

> **Âmbito:** UE · **Área:** Direito da União Europeia · **Código:** UE-051

Analyses the obligations to give access to and share data generated by connected products (IoT) or related services under Regulation (EU) 2023/2854 (Data Act), drafts the contractual clauses on data access and analyses the mandatory access interfaces for users and public authorities.

### ETAPA 1 — PROBLEMATIZAÇÃO
Dentro de <analise_da_situacao>:
- Tipo de produto/serviço: produto ligado (art. 2.º, n.º 5, Data Act — produto ligado à rede que gera ou recolhe dados sobre a sua utilização ou ambiente); ou serviço relacionado (acompanha ou está integrado num produto ligado)
- Papel da empresa: fabricante; prestador de serviços relacionados; utilizador; terceiro que pede acesso
- Natureza dos dados gerados: dados de utilização; dados de desempenho; dados de localização; dados de saúde (se wearable); dados pessoais ou não pessoais
- Questão em análise: obrigação de partilha com utilizadores; acesso por terceiros; acesso por autoridade pública; equidade de cláusulas contratuais B2B
- Dados em falta

### ETAPA 2 — ANÁLISE JURÍDICA
Dentro de <fundamentos_juridicos>:
- Âmbito (art. 1.º Data Act): dados de produtos ligados e serviços relacionados; excluídos — conteúdo criativo, conteúdo de comunicações eletrónicas; limitações para PMEs (art. 7.º, n.º 1)
- Obrigação de tornar os dados acessíveis ao utilizador (arts. 3.º-4.º): antes da compra, informação sobre que dados são gerados e como aceder; durante a utilização, acesso em tempo real e gratuito ao utilizador
- Partilha de dados com terceiros a pedido do utilizador (arts. 5.º-12.º): utilizador pode solicitar que o fabricante/prestador partilhe os dados com terceiro da sua escolha; o terceiro não pode usar os dados para fins diferentes do especificado; proteção de segredos comerciais (art. 4.º, n.º 6, e art. 5.º, n.º 6)
- Cláusulas contratuais B2B (arts. 13.º-14.º): proibição de cláusulas injustas em contratos de partilha de dados entre empresas; lista de cláusulas irrefutavelmente injustas (art. 13.º); cláusulas presuntas injustas (art. 14.º)
- Acesso por autoridades públicas em situações de emergência (arts. 15.º-22.º): condições estritas; proporcionalidade; prazo máximo; sem uso comercial
- Obrigações para prestadores de serviços de cloud (arts. 23.º-31.º) — ver Skill separada
- Interoperabilidade (arts. 32.º-41.º): interfaces obrigatórias para acesso a dados e portabilidade; normas técnicas a desenvolver
- Articulação com RGPD: o Data Act não derroga o RGPD; se os dados gerados incluem dados pessoais, ambos os regimes se aplicam cumulativamente; o «detentor de dados» no Data Act pode ser o «responsável pelo tratamento» no RGPD
